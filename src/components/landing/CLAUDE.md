# landing — Componentes da Landing Page

## Arquivos

- `Header.tsx` — Navbar com logo e CTAs
- `Hero.tsx` — Seção hero com headline e CTA principal
- `Problems.tsx` — Seção de problemas que o produto resolve
- `Features.tsx` — Grid de features do produto
- `HowItWorks.tsx` — Passo a passo de como funciona
- `Testimonials.tsx` — Depoimentos de clientes
- `Pricing.tsx` — Tabela de preços (planos: free, starter, pro, enterprise)
- `FAQ.tsx` — Perguntas frequentes (accordion)
- `FinalCTA.tsx` — CTA final antes do footer
- `Footer.tsx` — Rodapé com links
- `index.ts` — Re-exports de todos os componentes

## Padrões

- Componentes puramente visuais (sem lógica de negócio)
- Estilização 100% Tailwind CSS
- Responsivos (mobile-first)
- Compostos na `src/app/page.tsx`
